localStorage is readable by any JavaScript running on the origin, so a single XSS flaw (or a compromised npm dependency) would let an attacker copy the bearer token and use it from anywhere until it expires (60 minutes). An HttpOnly, Secure, SameSite cookie would keep it out of reach of page scripts.
