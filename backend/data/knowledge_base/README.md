# Curated Medical Knowledge Base

This folder contains the curated medical knowledge base for LabLens AI.
Knowledge documents provide educational information only. They must not diagnose
diseases, prescribe medication, or replace healthcare professionals.

This folder must not contain patient information, including uploaded reports,
patient identifiers, or individual laboratory results.

Every knowledge document must include source attribution for its educational
information, including the source title and URL.

## Initial scope

The initial scope is CBC and Lipid Profile laboratory tests. The supported tests
are exactly:

- Hemoglobin
- WBC
- Platelets
- HDL
- LDL
- Triglycerides
- Total Cholesterol

Curated knowledge documents will be stored as JSON files. No medical knowledge
documents have been added yet.
